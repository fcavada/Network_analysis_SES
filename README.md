# Network_analysis_SES

### Citation:
Cavada-Blanco, Francoise (2021), Los Roques benefits from coral reefs SEN, Dataset. https://github.com/fcavada/Network_analysis_SES/blob/main/losRoques_graph_2014.csv

Using a mixed-method approach,  a socio ecological network (SEN) was built from the flow of economic benefits that stakeholders obtain from coral reefs in Los Roques National Park. This dataset contains the nodes, links and weights used to analysed the topography and structure of the SEN to inform management.

### Methods
The Data set corresponds to a network where nodes (columns "in" and "out") are represented by six stakeholder groups and three ecosystem services of Los Roques National Park, a multi-use MPA in the Southern Caribbean. Nodes in each row are connected beecause an economic benefit derived from any of the ecosystem services is trasnferred between the two. The amount in bolivar (column "benefit_Bs_2014") and in US dollars ("benefit_USD_2014") for each link between the node pair is also included, calculated using the geometric mean of the annual echange rate variation in 2014 in the black market. The in and out columns represent the direction of the transfer.

Gross economic benfits were calculated using a combination of methods for valuations (market price, revealed preference, sustitution cost, travel cost, etc.) using official data and data collected through a socioeconomic assessment in between 2014 and 2016.
Usage Notes

The nodes abbreviations are as follows:

####Stakeholders
FS = Fishers
LG = Lodges
FP = Fish processors or "Tableros"
NS = lobster nurseries
DT = Fish carriers or "Lanchas"
TB = Touristic boat cooperatives
DS = Dive shops

####Ecosystem Services

RE = regulation, specifically reef framework and sanitation
SU = support, specifically biodiversity
PV = provisioning, specifically fisheries
